# 1.1 — Sắp xếp thư mục `core/`

> Phase: P1 · Bước (a) chuyển kiến trúc · Trạng thái: Plan 📝 | Làm ✅ | Review ⬜
> Tài liệu liên quan: [PLAN.md](../../PLAN.md) P1.1, [AGENTS.md](../../../../AGENTS.md) mục "Kiến trúc đích"

## 1. Mục tiêu

Mọi thứ dùng chung của app nằm trong `apps/erp/lib/core/`. Việc này chỉ **dời 4 file cấu hình** từ `lib/configurations/` vào `lib/core/config/`; không đổi tên class, không đổi hành vi. Các file khác trong `core/` để các việc 1.2–1.4 thay.

## 2. Hiện trạng

`lib/core/` đã có đủ `di/`, `errors/`, `formatting/`, `router/`, `session/`, `supabase/`. Riêng cấu hình môi trường còn nằm ngoài:

| File | Nội dung | Ai import |
|---|---|---|
| `lib/configurations/app_environment.dart` | enum `AppEnvironment` (development / staging / production) | `env.dart`, `test/configurations/env_test.dart` |
| `lib/configurations/env.dart` | `Env`: đọc `--dart-define` (`SUPABASE_CONNECTION_URL`, `SUPABASE_ANON_KEY`, `LOG_LEVEL`…) | `main.dart`, `env_banner.dart` |
| `lib/configurations/app_logging.dart` | `configureAppLogging()` | `main.dart` |
| `lib/configurations/env_banner.dart` | Widget dải "DEV / STAGING" | `main.dart` |

Đã grep toàn bộ `apps/erp` (trừ `build/`, `.dart_tool/`): chỉ có **2 chỗ** ngoài thư mục này import nó, là `lib/main.dart` (3 dòng) và `test/configurations/env_test.dart` (1 dòng). Bốn file import lẫn nhau bằng đường tương đối (`import 'env.dart';`) nên dời cả cụm không phải sửa bên trong.

## 3. Thay đổi

| File | Hành động | Nội dung |
|---|---|---|
| `lib/configurations/*.dart` (4 file) | Chuyển → `lib/core/config/` | Giữ nguyên tên file và nội dung |
| `lib/configurations/` | Xoá thư mục rỗng | — |
| `lib/main.dart` | Sửa 3 dòng import | `configurations/…` → `core/config/…` |
| `test/configurations/env_test.dart` | Chuyển → `test/core/config/env_test.dart` | Sửa import `package:erp/configurations/app_environment.dart` → `package:erp/core/config/app_environment.dart` |
| `test/configurations/` | Xoá thư mục rỗng | — |

Không đụng: `core/di`, `core/errors`, `core/session`, `core/router`, `core/supabase`, `core/formatting`.

## 4. Các bước

1. Tạo nhánh làm việc (khuyến nghị): `git switch -c refactor/p1-core` từ `refactor/simple-arch`.
2. Dời file bằng `git mv` để git giữ lịch sử:
   ```bash
   cd apps/erp
   mkdir -p lib/core/config test/core/config
   git mv lib/configurations/app_environment.dart lib/core/config/
   git mv lib/configurations/env.dart lib/core/config/
   git mv lib/configurations/app_logging.dart lib/core/config/
   git mv lib/configurations/env_banner.dart lib/core/config/
   git mv test/configurations/env_test.dart test/core/config/
   ```
3. Sửa `lib/main.dart`:
   ```dart
   import 'core/config/app_logging.dart';
   import 'core/config/env.dart';
   import 'core/config/env_banner.dart';
   ```
4. Sửa `test/core/config/env_test.dart`:
   ```dart
   import 'package:erp/core/config/app_environment.dart';
   ```
5. Kiểm tra không còn chỗ nào trỏ tới thư mục cũ:
   ```bash
   grep -rn "configurations/" lib test integration_test example
   ```
   Kết quả phải rỗng.
6. Commit: `refactor(erp): move app configuration into core/config`.
