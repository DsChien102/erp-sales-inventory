# Patterns exported by Flutter 1.4.1

Canonical public patterns are those exported by `lib/design_system.dart`:

- `VGap`
- `VField`, `VFieldLabel`, `VFieldDescription`, `VFieldError`
- `VPagePadding`
- `VSection`
- `VPageScaffold`
- `VResponsive`, `VResponsiveVisibility`
- `VContentWidth`
- `VResponsiveGrid`

HTML v2 does not promote Figma-only page templates or v1.6-only list/card archetypes to canonical status. Product screens compose the Flutter public API.
