# Prototype Theme 07 v4.0.0

Mở [index.html](index.html) để chạy ngay, không cần cài đặt hoặc máy chủ.

## Cách duyệt

1. Chọn Screen Group trong **Bộ điều khiển prototype**.
2. Chọn màn hình bằng nút có cả **số và tên màn hình**.
3. Chuyển State, vai trò và kịch bản dữ liệu.
4. Thao tác trong khung **Màn hình mobile kỳ vọng**.
5. Đối chiếu panel **Truy vết và review**.

## GitLab Pages

Thư mục này là static site. Khi job Pages publish thư mục `prototype/`, entrypoint là `index.html`.

## Biên bằng chứng

- Trạng thái: `STATIC_VALIDATED`.
- Visual baseline: VET45 Design System v1.0.0 — primary green 500, neutral/semantic tokens, 4pt spacing, touch target tối thiểu 44 px và một primary action mỗi Screen.
- Không gọi backend, không lưu dữ liệu thật và không chứng minh API đã được triển khai.
- Nguồn quyền lực cho Screen/State/Action: [screen-catalog.json](screen-catalog.snapshot.json).
