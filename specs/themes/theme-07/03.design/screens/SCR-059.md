## 4. Dữ liệu hiển thị / nhập

### 2. Experience contract

**User task:** Biết file đã sẵn sàng và phạm vi/as-of nào đã được xuất.

- `PROCESSING`: giữ report context; không suy ra failure từ delay.
- `COMPLETED`: file name, row count, report scope, as-of; navigation/file handoff `Lưu tệp` hoặc `Xong` không phải inventory mutation.
- `REJECTED_EXECUTION/FAILED`: nêu rõ chưa tạo file và lý do đọc/export; không biến thành UNKNOWN mutation recovery.
- `SOURCE_STALE`: không tạo file giả từ dữ liệu stale; quay về result để làm mới.
- Checksum/hash không phải Product decision → không render trong UI.

## 5. Trạng thái màn hình

- `PROCESSING`
- `COMPLETED`
- `REJECTED_EXECUTION`
- `SOURCE_STALE`
