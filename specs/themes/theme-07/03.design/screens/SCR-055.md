# SCR-055 — Báo cáo tồn / Thẻ kho

## 1. Mục đích

Xem delta và running balance theo ngày ghi nhận/nghiệp vụ.

## 2. Use Case liên quan

- `UC-15-02`
- `UC-15-03`
- `UC-01-03`

## 3. Entry / Exit

### 1. Identity & trace

| Thuộc tính | Contract |
|---|---|

| BJ | `BJ-15`, `BJ-01` |

| Primary object | Inventory report result or stock-card movement list |

## 4. Dữ liệu hiển thị / nhập

### 3. Information hierarchy

1. Scope + `Dữ liệu đến ...` (as-of) gần kết quả.
2. Report summary: số sản phẩm / hết hàng; total value only with finance permission.
3. Product or movement list.
4. Financial values/valuation adjustment only when permission allows.

Projection stale → persistent `VBanner` với as-of cũ; không dùng stale report làm mutation basis và không expose last processed sequence trong Product UI.

### Nội dung source còn lại / revision locks

### 2. UIF-15 context modes

- `INVENTORY_REPORT_RESULT`: summary + product rows; quantity stays per Product/UOM, **không cộng tổng quantity giữa các UOM**.
- `STOCK_CARD_RESULTS`: movement rows with delta + running balance; date semantics explicit.
- Product LOT breakdown is progressive disclosure. Product NONE không render lô giả.

### 5. Actions

- Row/card single destination → whole row tappable; no duplicate “Mở”.
- `Xuất báo cáo` là navigation sang SCR-058, không mutation inventory.
- Product row may open contextual lot/state breakdown sheet or filtered stock card.
