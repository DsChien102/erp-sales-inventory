### Nội dung source còn lại / revision locks

### v1.4.1 — Inventory Operations UX correction

- Waiting/source-owned order row là true read-only: không button, không chevron, không row navigation.
- Queue card giữ một supporting metadata line và concise state badge `Chờ đơn bán`.
- Actionable rows vẫn whole-row tappable; filters/search/order scoping không đổi.

### v1.4.2 — Queue information budget

- Queue helper giữ `Khách hàng · Kho`; bỏ count `N mặt hàng` nếu count không thay đổi quyết định ở queue.
- Status badge + order identity vẫn là primary scanning cues; waiting row vẫn true read-only.

### v2.7.0 — Figma DS expression

- Queue uses Figma `VSearchBar` + `VChip` + `DS v2 / List Row`. The v2.7.0 waiting=`Status` expression is historical and is superseded by the v2.7.3 same-collection Disabled Navigation rule below. No generic clickable card wrapper.
- Business state, authority, commit/finality and recovery rules above are unchanged.

### v2.7.3 — Collection consistency correction

- The v1.4.1/v2.7.0 visual rule that turned a waiting Order into a different non-navigation row is superseded.
- Every record in `Đơn cần lấy hàng` represents the same Order/Fulfillment record type, so the collection uses one component family and one variant geometry: `DS v2 / List Row`, `Type=Navigation`, `Density=Default`, `370×76`.
- Actionable Order = `State=Default`; source-waiting Order = `State=Disabled`. Disabled preserves the same navigation anatomy, including chevron, but the whole row is non-interactive and uses DS parent opacity `0.4` with `aria-disabled=true`.
- Availability/ownership differences are expressed by State + concise badge/copy, never by changing component Type or row size inside the same collection.

### v3.9.3 — Deep-review semantic closure

- Queue adds `VERIFYING / Đang xác minh bàn giao`: same Navigation anatomy in `State=Disabled`, non-actionable; it is not the source-owned `Đang chờ` filter semantics.
