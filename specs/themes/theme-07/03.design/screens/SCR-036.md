### v1.3.4 — UIF-07 context override

Khi `active UIF = UIF-07`, Product UI title/semantics là **Hàng chờ trả nhà cung cấp** và list chỉ gồm source-approved supplier-return requests. Không dùng generic inventory-triage wording để yêu cầu user quyết định trạng thái. UIF-09/UIF-10 giữ contract context cũ.

### v1.3.6 — UIF-07 queue override

Trong `UIF-07`, đây là **Hàng chờ trả nhà cung cấp**. Lifecycle badge giữ `Chờ bàn giao`; event `Yêu cầu vừa thay đổi` chỉ là supporting copy, không trở thành lifecycle status. Normal queue không dùng banner để giải thích rule source-authorized. Row mở `SCR-037 — Chuẩn bị hàng trả`.

### UIF-07 override v1.3.9 — Supplier-return task queue

- Default `Tất cả`; quick chips `Tất cả / Cần chuẩn bị / Sẵn sàng / Đang chờ`; search có no-result.
