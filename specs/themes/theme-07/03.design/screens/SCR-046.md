### Nội dung source còn lại / revision locks

### User task

Eligible independent approver xem exact non-zero variance snapshot và quyết định APPROVE hoặc REQUEST_RECOUNT; không sửa số đếm.

### Behavior

- Chỉ mở khi latest recount variance ≠ 0 và current ApprovalCase subject=`STOCK_COUNT_SESSION`.
- Read-only: scope/cutoff, latest recount, variance, risk/value-basis status, contributor context cần thiết.
- Mọi actor đã góp FIRST/RECOUNT evidence của current snapshot bị loại khỏi approver eligible; self/contributor approval blocked server-side.
- Risk value là `FINANCIAL_RESTRICTED`: server omit khi không quyền, không CSS mask.
- `Duyệt và điều chỉnh`: recheck policy/round/lock/Official Cost/surplus basis; stale → no adjustment và yêu cầu case mới.
- `Yêu cầu xem lại`: reason required, old case immutable, giữ lock và tạo recount requirement.
- Không có cancel trên approval task.

### DS

Mobile/Detail + Info Row + coherent review section (không badge/text rời rạc) + VBanner exception + Sticky Footer. Primary “Duyệt và điều chỉnh”; secondary “Yêu cầu xem lại”; Confirmation Sheet tương ứng.
