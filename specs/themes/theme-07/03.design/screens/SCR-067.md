## 4. Dữ liệu hiển thị / nhập

### 2. Experience contract

**User task:** Chọn dữ liệu đầu kỳ và khai các số kiểm soát độc lập để hệ thống kiểm tra.

- Dùng ngôn ngữ người dùng: `Ngày chốt số dư`, không bắt user hiểu “cut-off”.
- File nguồn là evidence/input; hệ thống không tự tạo Product/UOM/LOT khi file sai.
- `Tổng số lượng kiểm soát` và `Tổng giá trị kiểm soát` là **user-supplied control totals**, không derive từ chính file rồi tự so với nó.
- Quantity tổng chỉ dùng để đối chiếu migration; không dùng tổng quantity này làm report vận hành sau activation vì có thể trộn nhiều UOM.
- Không có `Lưu nháp`; persistence an toàn là system concern.
