### Nội dung source còn lại / revision locks

### User task

Đếm lại đúng discrepant lines, biết đây là vòng recount thứ mấy và các value-basis blockers còn thiếu.

### Behavior

- Sau FIRST submit mới được hiển thị book/first count/variance.
- Mỗi recount submit tạo immutable `StockCountSubmission`; UI hiển thị `Lần đếm lại N`, không sửa evidence round trước.
- Line vẫn hiện Product + physical stock state + LOT + base UOM để tránh nhầm key.
- Surplus value basis là server-authoritative status; counter không nhập giá/filename/evidence taxonomy giả.
- Missing basis → `PRICE_BASIS_REQUIRED`, giữ lock, disable submit-to-approval; authorized cancel vẫn có reason confirmation.
- Recount variance=0 → complete + unlock, no ApprovalCase; non-zero + basis ready → submit xong maker task, handoff approver.

### DS

Mobile/Form + VBanner + Info Row + recount rows + VNumericKeypadSheet + Sticky Footer. Primary “Gửi kết quả đếm lại”; danger secondary “Hủy phiên” khi cancellable.
