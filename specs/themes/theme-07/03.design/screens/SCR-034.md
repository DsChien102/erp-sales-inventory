# SCR-034 — Ngoại lệ lô cần duyệt

## 1. Mục đích

Approver task list + exact LINE_EXCEPTION decision bound to immutable subject snapshot hash; UI trình bày maker, source return/order context, Product/UOM, quantity, source↔actual LOT, reason và evidence thay vì raw case/version IDs.

## 2. Use Case liên quan

- `UC-06-02`

## 3. Entry / Exit

### v1.4.3 — Approver entry

- Entry class: `ACTOR_HANDOFF_TASK`. Chỉ approver worklist/notification/deep-link được giao mở screen này; không phải continuation navigation của maker.
- AppBar/list state nói rõ `Việc dành cho người phê duyệt`; detail nói đây là quyết định trên bằng chứng maker đã gửi.
- Sau decision, exit quay về approver task list. Maker re-entry ở request gốc sau khi authoritative decision có hiệu lực.
