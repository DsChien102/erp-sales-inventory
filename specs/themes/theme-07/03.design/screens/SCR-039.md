### Nội dung source còn lại / revision locks

### v1.3.9 — Exact-source final handover review

- Chỉ mở khi tất cả current source allocations đã physical verify và không mismatch.
- Review hiển thị supplier/request/source và actual Product+UOM+LOT/HSD/qty; không aggregate quantity khác UOM.
- Đây là một explicit irreversible review surface; không second commercial approval và không confirmation modal lặp.
- Commit recheck source/version. Stale/source change quay về SCR-037 với granular delta.
- `ACT-08-RTV` giảm physical/value chỉ tại actual handover.

### v1.4.1 — Inventory Operations holistic UX correction

- Normal review bỏ per-allocation helper `Đã kiểm thực tế` và bỏ informational banner thường trực.
- Normal handover rule chuyển thành quiet footnote; source stale/delta vẫn là warning/blocker.
- Review vẫn tách Product/UOM/LOT và không aggregate quantity khác UOM.

### v1.4.2 — Final review hierarchy

- Final review group theo Product+UOM parent; LOT/non-LOT allocation là child rows với semantic labels.
- Bỏ compact count `mặt hàng · phần` vì object count dễ mơ hồ; hierarchy trên màn tự giải thích scope.
- Không thay đổi commit semantics, source recheck hoặc mixed-UOM guard.

### v2.9.1 — UIF07 final review composition correction

- Context is reduced to decision-relevant grouped `Info Row`: Supplier, request and warehouse.
- Product+UOM uses a structural section heading, not a compact List Row. A quantity badge may summarize only allocations inside that exact Product+UOM group.
- LOT/non-LOT allocations use `Key-value Row / Default`; no grand total across UOM and no duplicate confirmation modal.

### v2.9.2 — Final-review grouping correction

- Product+UOM is a canonical `List Row / Status / Compact` inside a coherent group surface. Per-LOT/non-LOT values remain `Key-value Row / Default`.
- No floating product text/badge; no Summary Card added just for decoration; quantity remains scoped to exact Product+UOM.

### v2.9.3 — Final-review grouped collection

- Supersedes the v2.9.2 per-Product surface and quantity badge.
- `Hàng sẽ bàn giao` owns one grouped surface. Product+UOM uses `List Row / Status / Compact` with semantic `Đã kiểm`; LOT/non-LOT evidence uses `Key-value Row / Default`.
- Raw quantity remains in the Key-value value column; `VBadge` is reserved for semantic state.

### v3.9.5 — Final handover semantic lock

- Decision context includes Supplier, return request, source document and Warehouse; raw `source_version` is not shown.
- When a source allocation required a multi-state composition, review shows a concise **Nguồn tồn** fact for that Product/UOM/LOT only.
- Commit requires current stable allocation identity + exact `RTV_PENDING` source slices + physical verification + actor handover assertion.
- Commercial supplier price is not a guard. Inventory value reduction uses official cost; commercial price/debit-note/payable difference stays Purchase/Accounting-owned.
- `ACT-08-RTV` creates immutable source-agnostic HandoverEvidence with actor/server time and allocation/source-slice lineage.
