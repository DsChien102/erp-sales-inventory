# Archived SQL drafts

Các file trong thư mục này chỉ giữ lịch sử thiết kế. Chúng đã được draft mới
ở thư mục cha supersede và không được apply, bundle hoặc promote.

Tool promote hiện chỉ đọc các file `.sql` trực tiếp trong `_drafts/`, vì vậy
không di chuyển file archive trở lại thư mục cha nếu chưa chủ động phục hồi
thiết kế cũ.
